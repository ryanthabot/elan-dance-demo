# Élan Dance Co. — Website Design Spec

**Date:** 2026-07-25
**Status:** Approved by user — ready for implementation planning
**Business type:** Local service business (dance instruction)
**Working name:** Élan Dance Co. (placeholder — user will finalize)

---

## 1. Purpose & Audience

A single-page marketing website for a dance studio that teaches **solo/studio styles** (ballet, jazz, contemporary, hip-hop, lyrical, tap) across a wide audience range, delivered via **three formats**: in clients' homes, online (video calls), and in-studio.

### Primary goals of the site
1. Convert visitors into **lesson inquiries** (the contact form is the #1 conversion).
2. Communicate **trust and professionalism** to parents, couples, and adult beginners.
3. Convey **artistic credibility** to teens and competitive dancers.
4. Present **pricing transparently** across formats and purchase types.

### Target audiences (in priority order)
1. Parents of children (ages 3–12)
2. Couples planning a wedding first dance
3. Adult beginners
4. Teens (ages 13–17)
5. Seniors
6. Competitive dancers

## 2. Brand Foundation

### Business name
**Élan Dance Co.** (working placeholder; *élan* = energy, style, enthusiasm).

Evaluation criteria applied (use the same checklist when user finalizes their real name):
- Memorable, easy to spell/pronounce, positive associations, flexible across audiences, likely available, no limits on expansion.
- Caution: accent mark (é) complicates URLs — use `elan` in domains, `Élan` in logo.

### Tagline
**Primary:** "Move with intention."

Alternates (for other contexts):
- "Dance, beautifully." (business cards)
- "Your stage. Your story." (hero alt)
- "Where movement meets you." (broader audience)
- "Train. Express. Belong." (teen/competitive)
- "From first steps to center stage." (kids/parents)

### Visual direction: "Stage Light" (hybrid)
Dark dramatic base + warm light content sections + single amber accent. Reads as premium performing-arts without alienating families. Selected over "pure bold" (too cold for families) and "pure light" (forgettable).

### Brand palette (4-color core + 3 neutrals)

| Role | Hex | Use |
|---|---|---|
| Stage Black | `#0E0E10` | Hero/footer/dark sections |
| Warm Cream | `#FAF6F0` | Main content background |
| Spotlight Amber | `#E0A458` | CTAs, highlights, links |
| Deep Plum | `#3D2B3D` | Secondary text/buttons on light |
| Soft Gray | `#8A8580` | Borders, muted text |
| Ink | `#1A1A1F` | Body text on cream |
| Light Plum Tint | `#F4EEF2` | Subtle section backgrounds |

### Typography
- **Headlines:** Cormorant Garamond (serif, elegant, theatrical) — Google Fonts
- **Body/UI:** Inter (humanist sans, readable, modern) — Google Fonts

### Imagery direction
- Hero & section breaks: dramatic, high-contrast dance photography (single dancer, spotlight, dark background; silhouettes/motion blur welcome).
- Audience sections: warmer lifestyle photos (people enjoying dance).
- Unified warm-tone color grading across all photos.
- Avoid: generic stock group-smiling clichés, clip-art, neon/cartoonish imagery.

## 3. Trust & Professionalism Signals

Baked into the design:
1. Photography over illustration.
2. Real studio address + embedded map.
3. Instructor credentials visible (bio + training/experience).
4. Transparent pricing (no "call for pricing" walls).
5. Testimonials with full names + context.
6. Professional contact info (domain-based email, real phone, response-time promise).
7. Trust badges & policies (cancellation, insurance, child-safety statement).
8. Consistent brand execution across site.

---

## 4. Site Architecture

**Single-page scrolling site** with sticky anchored navigation.

**Rationale:** one page = one conversion path; mobile-friendly; easy to maintain; strong SEO; fast to build/host.

### Navigation (sticky, always visible)
- Left: `Élan Dance Co.` logo
- Center/right: Classes · Pricing · Audiences · About · Contact
- Far right: **"Book a Lesson"** button (amber)

## 6. Technical Approach

- **Files:** `index.html` + `styles.css` + `script.js` (minimal: mobile nav toggle, smooth scroll, form validation).
- **Fonts:** Google Fonts via `<link>` — Cormorant Garamond + Inter.
- **Responsive:** mobile-first; tested at phone/tablet/desktop widths.
- **Accessible:** semantic HTML, alt text on all images, keyboard-navigable nav, sufficient color contrast (WCAG AA).
- **SEO:** descriptive `<title>`, meta description, Open Graph tags, `schema.org/LocalBusiness` structured data.
- **Images:** Unsplash dance photos as placeholders; each clearly commented in code for easy swapping.
- **No build tools, no dependencies** — opens in any browser, hosts anywhere (Netlify, GitHub Pages, etc.).
